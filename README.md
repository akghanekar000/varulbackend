# Varul Backend

This repository is the initial FastAPI foundation for Varul.

This milestone is intentionally minimal and does not include:
- MCP
- database integration
- authentication
- AI-provider integrations
- code-execution tools
- deployment automation

## Python version

This project is designed for Python 3.11.x, which is compatible with current FastAPI and Pydantic versions and is widely supported by free hosting platforms.
